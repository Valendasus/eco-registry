# ЭкоРеестр

Картотека граждан и обращений для регионального оператора по обращению с ТКО. Структура взята из модуля «Управление обращениями» портала ППК РЭО и переложена на другую компоновку.

## Что есть

- **Главная** — сводка по реестру: граждане на учёте, обращения за 30 дней, решено в срок, задолженность. Динамика обращений по месяцам, каналы поступления, тематика, возрастно-половая структура, льготные категории, муниципальные образования, нагрузка исполнителей, последние обращения.
- **Картотека** — 100 000 граждан, виртуализированная таблица, поиск по ФИО / СНИЛС / номеру карточки / лицевому счёту / телефону, фильтры (район, статус, пол, возраст, льготы, долг, открытые обращения, дата постановки на учёт), сортировка, настройка колонок, выгрузка в CSV. При выборе строки справа открывается краткая карточка по разделам. Стрелки ↑ ↓ двигают выделение, Enter открывает карточку.
- **Карточка гражданина** — 10 разделов: основное, документы, адреса, контакты, семья, образование и работа, соцподдержка, лицевой счёт ТКО с графиком начислений, обращения, история и файлы. Режим просмотра и редактирования, валидация (в том числе контрольная сумма СНИЛС и ИНН), маски ввода, регистрация нового обращения.
- **Новая карточка** — пошаговый мастер с проверкой каждого шага и автосохранением черновика.

Светлая и тёмная тема.

## Стек

React 19, TypeScript, Vite, MUI, MUI X Date Pickers, React Router, TanStack Query, TanStack Virtual, React Hook Form, Recharts, Day.js.

## Запуск

```bash
npm install
npm run dev
```

Сборка — `npm run build`, линтер — `npm run lint`.

## Как устроены данные

Бэкенда нет, данные генерируются детерминированно по id гражданина (`src/mock`), поэтому при каждом запуске реестр одинаковый.

Чтобы список на 100 000 записей не тормозил интерфейс, весь реестр живёт в Web Worker (`src/api/registry.worker.ts`): там же фильтрация, сортировка и подсчёт статистики для главной. В основной поток возвращается только массив id, а строки таблицы собираются лениво для видимой области. Полная карточка (150+ полей и связанные таблицы) генерируется по запросу.

Изменения и новые карточки сохраняются в `localStorage` и подхватываются воркером при следующем запуске.

## Структура

```
src/
  api/          воркер реестра, клиент, хуки React Query
  app/          тема, роутер, провайдеры
  components/   поля форм (просмотр/редактирование), общие UI-компоненты
  entities/     типы и справочники
  layout/       меню и шапка
  lib/          форматирование, маски, валидаторы, утилиты
  mock/         генератор тестовых данных
  pages/        главная, картотека, карточка, мастер создания
```
